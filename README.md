# Atari TV

A TV-friendly Atari 2600 emulator for Android TV: D-pad-navigable game shelf,
SAF ROM library, River-Ride-style two-player input routing, unified save states
and a pause menu — all ten-foot UI.

## Build

Prerequisites (exact pins from `_bmad-output/architecture.md`):

```bash
export ANDROID_HOME=~/workspace/android-sdk
export JAVA_HOME=~/workspace/jdk17/jdk-17.0.13+11
export GRADLE_USER_HOME=~/workspace/gradle-home-atari   # proxy-only props; never touch /home/hatch/.gradle
export PATH=$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH
export https_proxy=http://127.0.0.1:3129 http_proxy=http://127.0.0.1:3129
```

1. **Build the core** (Stella, arm64-v8a, 16 KB-aligned; gate fails the script
   if any `LOAD` segment is not `0x4000`-aligned):

   ```bash
   tools/build_core.sh
   # -> app/src/main/jniLibs/arm64-v8a/stella_libretro.so
   ```

   Note: `APP_CPPFLAGS=-fexceptions` is passed on the ndk-build command line
   because NDK r28's ndk-build ignores the `APP_CPPFLAGS := -fexceptions`
   assignment in the core's own `Application.mk`.

2. **Generate the test ROM**:

   ```bash
   python3 tools/gen_test_rom.py
   # -> app/src/main/assets/test_cart.bin (2048 bytes, vectors -> $F800)
   ```

3. **Build the app**:

   ```bash
   ~/workspace/gradle/gradle-8.9/bin/gradle :app:assembleDebug
   # (or ./gradlew assembleDebug once the wrapper distribution is cached)
   ```

### LibretroDroid vendoring (plan B)

JitPack is unreachable from the build sandbox, so LibretroDroid 0.14.0 is
used as a source module (`vendor/LibretroDroid`, pinned commit above,
`settings.gradle` maps it to `:libretrodroid`). The vendor tree is **not**
committed — it is regenerated reproducibly by:

```bash
tools/vendor_libretrodroid.sh   # clone @ pinned commit, apply patches, prune
tools/build_core.sh             # build the Stella core into app/src/main/jniLibs/
```

Four minimal patches are applied by the script (see
`tools/libretrodroid-atari-tv.patch`):

- `libretrodroid/build.gradle`: `compileSdkVersion 33` → `34`
  (android-33 is not installed in this SDK)
- `libretrodroid/build.gradle`: `ndkVersion "28.2.13676358"` pin
  (AGP otherwise picks r27)
- `libretrodroid/build.gradle`: `ndk { abiFilters 'arm64-v8a' }` added
  (skip the other 3 ABIs in the module's CMake native build; the app ships
  arm64-v8a only)
- `libretrodroid/src/main/cpp/libretrodroid.h`, `rumble.h` and
  `utils/javautils.h`: `#include <functional>` added to each (NDK r28
  libc++ fix; upstream sources otherwise untouched)

## Test ROM

`tools/gen_test_rom.py` hand-assembles a 2K NTSC cart (no assembler needed):

- 6 horizontal color bands (COLUBK change per 32 scanlines, 192-line kernel)
- one 8px white square (player 0) bouncing with edge physics
- joystick 0 directions nudge the square; fire recenters it
- 262 scanlines/frame: 3 VSYNC + 37 VBLANK + 192 kernel + 30 overscan

The SWCHA/INPT4 bit order, fire polarity and the RESP0 positioning formula
were verified against the pinned Stella core source before encoding. A
throwaway 6502 logic simulator validated: 192-line kernel, RESP0 strobe cycle,
300 frames of bounded bouncing physics.

## Input mapping

| Physical input | Emulator target |
|---|---|
| TV remote D-pad | Joystick 1 (port 0) directions |
| Remote OK / gamepad A | Fire (RetroPad B; A↔B/X↔Y swap applied for gamepads) |
| Gamepad #1 / #2 (sticky deviceId→port) | RetroPad port 0 / 1 |
| Gamepad left stick | D-pad directions (0.25 deadzone, via MOTION_SOURCE_DPAD) |
| Gamepad START / remote BACK | Pause menu (intercepted; core maps START→ConsoleReset) |
| Gamepad SELECT | Console Select (forwarded) |
| Pause menu: Console SELECT/RESET, Difficulty L/R | Synthetic momentary presses on port 0 |

## Saves

Per game (SHA-256 of ROM bytes): 3 manual slots + 1 auto slot under
`files/saves/<sha256>/`, 320px JPEG thumbnails via PixelCopy, `meta.json`
with timestamps, play time and core SHA. Auto-save on "Back to shelf",
"Reset game" and activity pause. Shelf shows ▶ Continue when an auto save
exists.
